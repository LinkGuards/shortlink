Tentang Project

⚡

100% Static

Tanpa backend, tanpa database. Semua shortlink disimpan di localStorage browser Anda. Deploy di GitHub Pages, Netlify, atau Cloudflare Pages — gratis selamanya.

🎯

URL Bersih

Menggunakan trik 404.html sehingga shortlink berbentuk /s/kode-anda — bukan query string panjang. Tinggal copy, bagikan, selesai.

🔄

Auto Update Artikel

GitHub Actions cron job mengambil RSS feed brightdailyhub.my.id/feed.php setiap hari dan menyimpannya sebagai JSON di repo. Tidak perlu CORS proxy.

🔒

Privasi by Design

Shortlink tidak dikirim ke server mana pun. Tidak ada tracking, tidak ada analitik pihak ketiga. Yang Anda buat hanya milik Anda di browser itu.

Siap Deploy?

  1. Fork / upload folder ini ke repository GitHub baru.
  2. Buka Settings → Pages → Source: Deploy from a branch → main / /.
  3. Tunggu 1–2 menit. Site live di https://<username>.github.io/<repo>/.
  4. Aktifkan GitHub Actions dengan izin Read and write agar artikel auto-update berjalan.

Lihat README.md untuk panduan lengkap dan kustomisasi.
